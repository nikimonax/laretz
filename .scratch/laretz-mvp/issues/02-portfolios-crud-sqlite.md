# 02: Портфели: CRUD end-to-end (+ sqlite фундамент)

**What to build:** Первый вертикальный срез через все слои: пользователь создаёт, переименовывает и удаляет портфели на `/`. Заодно закладывается storage-фундамент: открытие БД, миграции, sqlc, fx-модуль storage. Удаление портфеля — каскад операций по контракту (сквозная проверка появится вместе с операциями в 05). См. спеку: «Схема sqlite», «Маршруты».

**Blocked by:** 01 (Скелет приложения и HTTP-сервер).

**Status:** done

- [x] БД открывается в `os.UserConfigDir()/laretz` (linux: `~/.config/laretz`, windows: `%AppData%`), `laretz.db` рядом с `config.yaml`; goose-миграции применяются при старте, schema содержит portfolio
- [x] `/` показывает список портфелей (пока только имя) и empty state, когда их нет
- [x] Создание и переименование через модалку на `/`, POST + PRG, ошибки валидации — перерисовка формы
