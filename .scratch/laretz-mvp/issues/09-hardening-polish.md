# 09: Харденинг и полировка

**What to build:** Сквозной проход по всему happy path и краям: полный сценарий от первого запуска до графика, edge-кейсы, финальная чистка. После тикета приложение годится для ежедневного использования (MVP). См. спеку: «Пользовательские сценарии», «Out of MVP» (там же список осознанно отложенного).

**Blocked by:** 08 (Стоимость портфеля и график).

**Status:** ready-for-agent

- [ ] Смоук всего пути: первый запуск → интеграция → синк → импорт → операции → цены → график; пустые состояния на каждой странице
- [ ] Edge-кейсы: пустой портфель, минус-баланс в стоимости, операция задним числом расширяет HoldingInterval (дозагрузка только гэпа), re-link после цен (новая дозагрузка), удаление актива с операциями блокируется
- [ ] Ошибки форм перерисовкой без потери введённого; пагинация на границах (последняя страница, пустые таблицы)
- [ ] Локализация copy EN, без доменного жаргона (Asset, не CanonicalAsset)
- [ ] lint green, весь тестовый набор green, go.mod без неиспользуемых зависимостей
