# 08: Стоимость портфеля и график

**What to build:** Портфель обретает стоимость: исторический график на uPlot через `GET /api/portfolio/:id/chart`, стоимости в позициях и на `/`. Форвард-филл — только для отображения (в БД дыры остаются), с бейджами «не актуальная» и «часть активов без цены». Отрицательный баланс уменьшает стоимость. См. спеку: «Правила отображения», ADR-0002.

**Blocked by:** 07 (FetchQuotes: дозагрузка цен).

**Status:** ready-for-agent

- [ ] Valuation в domain: стоимость часа = Σ (баланс × цена); цена = PricePoint часа, иначе последняя известная (форвард-филл, флаг stale)
- [ ] Актив без единой цены исключается из суммы + бейдж «часть активов без цены»
- [ ] `/api/portfolio/{id}/chart`: JSON-ряд для uPlot (часы активных интервалов, carried-сегменты); график рендерится на странице
- [ ] В позициях — стоимость позиции; на `/` — стоимость каждого портфеля с флагами staleness
- [ ] Тесты Valuation: форвард-филл через gap, дневная гранулярность в hourly-сетки, минус-баланс, актив без цен
