# 06: Позиции и балансы

**What to build:** Страница портфеля показывает живой состав: по каждому активу с ненулевым балансом — Position с балансом, выведенным из операций (ничего не хранится). Колонка текущей цены появляется, но пока возвращает «нет цены» — цены приходят в тикете 07. Fee на баланс не влияет. См. спеку: «Правила отображения», глоссарий: Balance, Position, HoldingInterval.

**Blocked by:** 05 (Операции: CRUD в портфеле).

**Status:** ready-for-agent

- [ ] Таблица позиций на `/portfolio/:id`: Asset, баланс; текущая цена с меткой as-of только при балансе ≠ 0, иначе «нет цены»
- [ ] BalanceTimeline в domain: баланс в произвольный момент из операций; Buy/Sell знаки, отрицательные балансы допустимы
- [ ] HoldingInterval: границы — часы граничных операций включительно; незакрытый интервал — до текущего часа
- [ ] Позиции с нулевым балансом не показываются в позициях (но видны в операциях)
- [ ] Юнит-тесты таймлайна: границы включительно, минус-балансы, операция задним числом расширяет интервал, fee не двигает баланс
