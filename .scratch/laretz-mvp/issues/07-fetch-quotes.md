# 07: FetchQuotes: дозагрузка цен

**What to build:** Кнопка на странице портфеля: «догрузить цены». Ядро считает недостающие диапазоны (required по HoldingInterval минус QuoteCoverage) и запрашивает их у источника через QuoteFeed-порт (`internal/app/interfaces`). В БД попадают только реально полученные данные: существующие PricePoint не перезаписываются, дыры не синтезируются, дневные точки кладутся в 00:00 UTC. См. спеку: «FetchQuotes — алгоритм», ADR-0002.

**Blocked by:** 06 (Позиции и балансы).

**Status:** done

- [x] `POST /quotes/fetch` + PRG; команда глобальная — по всем портфелям и активам сразу
- [x] CoveragePlanner: HoldingInterval → требуемые часы через primary link → минус QuoteCoverage → непрерывные диапазоны на ExternalAsset
- [x] Upsert только отсутствующих часов; повторный клик без изменений не делает запросов
- [x] Coingecko-адаптер: hourly для диапазонов ≤ 90 дней, daily дальше (гранулярность day), старше ~365 дней — пусто; пауза между запросами; demo-key заголовком
- [x] Актив без линка/без операций цен не получает

Тесты (CoveragePlanner: гэпы, дозадним-числом; адаптер на fake-HTTP: гранулярность и раскладка по слотам) — в 09, единый тестовый проход в конце MVP.
